## Deployment & CI/CD Pipeline

The repository utilizes **GitHub Actions** (`.github/workflows/deploy.yml`) to deploy all applications under a single unified GitHub Pages host:

- **Dependency Caching:** Multi-project `package-lock.json` caching across all React applications.
- **Root Landing Page:** `Projects/React/Hub` is built and deployed directly to `/WebDev/`.
- **Sub-Route Hosting:** Sub-projects are nested into `/WebDev/CV-Application/`, `/WebDev/Memory-Card/`, and `/WebDev/Shopping-Cart/`.
- **SPA 404 Routing:** Configured with fallback handling (`404.html`) to prevent page reload errors on client-side routing.

## Local Development

To run any of the React applications locally:

```bash
# Clone the repository
git clone https://github.com/Artur-SLO/WebDev.git
cd WebDev

# Example: Run the Portfolio Hub
cd "Projects/React/Hub"
npm install
npm run dev

# Example: Run the Shopping Cart
cd "../Shopping-Cart"
npm install
npm run dev
```
